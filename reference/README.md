# Reference models

Acceptance oracle for the generator tests. Based on the
[Small Parts Assortment System](https://www.printables.com/model/75204-small-parts-assortment-system)
on Printables, modified by the repo owner. Personal use.

| File | What it is |
|---|---|
| `SPAS-box_1x1.stl` | Original 1×1, height 1 – label wedge up to the top edge |
| `SPAS-box_2x1_smooth_v2.stl` | Template 2×1, height 1, lowered wedge, rounded floor (feet on a 44.6 pitch – the generator fixes this to 45) |
| `SPAS-box_1x1_half_stackable_v3.stl` | Template 1×1, height 0.5, lowered wedge |
| `SPAS-grid_4x4.stl` | Template 4×4 grid |
